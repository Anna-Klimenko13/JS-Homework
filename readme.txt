# Starter — заготовка для роботи

Скопіюйте цю теку у свій репозиторій (можна перейменувати в `solution/`) і працюйте всередині.

```
starter/
├── index.html          ← ваша розмітка картки ліда
├── css/
│   ├── tokens.css      ← дизайн-токени проєкту. НЕ РЕДАГУВАТИ
│   ├── demo.css        ← оформлення демо-сторінки, не частина компонента
│   └── lead-card.css   ← ваш компонентний CSS
├── js/
│   └── lead-card.js    ← Alpine-компоненти (Рівень 2)
├── SOLUTION.md         ← заповнити обов'язково
├── .prettierrc
└── .editorconfig
```

## Запуск

Ніякої збірки не потрібно — це статика. Відкрийте `index.html` подвійним кліком.

Тримайте так і надалі: підключайте свій JS звичайним `<script defer>`, а не `type="module"`
(модулі на `file://` блокуються CORS-ом). Якщо все ж захочете модулі або dev-сервер —
можна, але тоді напишіть команду запуску в `SOLUTION.md`.

## Форматування

```bash
npx prettier --write "**/*.{html,css,js}"
```

Конфіг уже лежить поруч (`.prettierrc` + `.editorconfig`): 4 пробіли, ширина 120.

## Про `tokens.css`

Це реальний файл із проєкту (`resources/css/config.css`) — усі кольори, радіуси, тіні системи.
Правити його не треба: у нас він живий і оновлюється централізовано, а акцентний колір
взагалі налаштовується адміністратором у рантаймі.

Якщо потрібного значення там немає — заводьте **локальну змінну компонента**
(`--lc-…`) у своєму `lead-card.css` і фіксуйте її в `SOLUTION.md`.

## Alpine.js

Підключений з CDN у `index.html`. Версія 3 — та сама, що в проєкті.
Документація: <https://alpinejs.dev/>

Потрібен офлайн — просто скачайте `cdn.min.js` поруч і поміняйте `src`.
